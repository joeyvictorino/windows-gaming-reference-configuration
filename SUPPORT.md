# Support

WGRC is a personal open-source project, not a Microsoft support channel.

Before opening an issue:

1. run `Audit`
2. run `Verify`
3. run `Collect`
4. review the diagnostic ZIP for privacy
5. use the bug or compatibility issue template

Include the exact WGRC version/commit and Windows build.

For Windows product support, licensing, account recovery, Microsoft Store billing, Xbox account issues or Lenovo hardware warranty, use the relevant vendor's official support channel.
