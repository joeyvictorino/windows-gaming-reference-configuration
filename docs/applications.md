# Application curation

Permanent layer:

7-Zip, mpv, Everything, PowerToys, Playnite, Discord, Steam, Xbox, Ubisoft Connect, EA app, Epic Games Launcher, Battle.net and Microsoft 365.

PowerToys reference modules: **Run, Peek, PowerRename**. WGRC intentionally does not write version-fragile PowerToys JSON.

Windows protects default-app choices, so WGRC does not forge UserChoice hashes. Set mpv through Settings.

Commissioning tools such as HWiNFO, Afterburner/RTSS, OCCT, 3DMark, Cinebench and WizTree are not installed by default.
