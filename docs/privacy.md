# Privacy

Defaults:

- Windows advertising/promotion surfaces: off where documented policy supports it
- Advertising ID: off
- tailored experiences: off
- Widgets/news: off
- web search integration: off where supported
- Windows diagnostic data: **Required**
- Windows Error Reporting: **enabled**
- unsolicited additional WER data: restricted

WGRC does not delete diagnostic services or claim "zero telemetry" through endpoint blocking.

Microsoft diagnostic policy:
https://learn.microsoft.com/windows/client-management/mdm/policy-csp-system

Microsoft WER guidance:
https://learn.microsoft.com/troubleshoot/windows-client/system-management-components/windows-error-reporting-diagnostics-enablement-guidance

Privacy Guides informed the supported-policy/no-modified-build philosophy:
https://www.privacyguides.org/en/os/windows/
