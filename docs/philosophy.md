# Philosophy

WGRC is not a debloat script.

It optimizes for **ready to game, quiet, supported, reversible, understandable, measured, curated and secure**.

A lower Task Manager process count is not a goal. The project changes behavior only when there is a concrete user-facing reason.

"Apple-like" means product discipline, not macOS imitation. WGRC does not install macOS themes, shell patchers, Rainmeter dashboards or replacement system icons. Elegance comes from native Windows with fewer interruptions and better defaults.


## No private Microsoft material

The author's Microsoft background influences the operating standard, not the source material.

WGRC contains no proprietary Microsoft code, confidential response playbooks, internal tools, unpublished policy, credentials, telemetry, or customer information.

Every configuration decision must be defensible from public Windows/vendor behavior and public documentation.
