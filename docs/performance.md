# Performance

The first performance requirement is **no regression**.

WGRC enables Windows Game Mode but does not force global GPU maximum-performance profiles, disable cores, alter timers, disable pagefile, or install Process Lasso/ISLC/game boosters.

HAGS, VBS/HVCI A/B testing, GPU undervolting/overclocking and OEM-specific tuning are deliberately separate experiments.

Useful metrics: average FPS, 1% lows, frame-time variance, repeatability, idle CPU/disk activity, reliability and game compatibility.

Not metrics: lowest process count, lowest idle RAM, one synthetic benchmark run.
