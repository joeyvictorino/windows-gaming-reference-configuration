# Code of Conduct

This project expects professional, technical disagreement without personal attacks.

The community standard is simple:

- criticize code, defaults, evidence and methodology freely
- explain the technical reason
- provide reproduction data when possible
- do not harass contributors or users
- do not post credentials, recovery keys, tokens or other private data
- do not use issue threads for political or unrelated disputes

The project is also compatible in spirit with the Microsoft Open Source Code of Conduct:

https://opensource.microsoft.com/codeofconduct/
